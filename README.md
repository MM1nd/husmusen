# Husmusen

Husmusen is a household planning app, being built to help people coordinate everyday life at home.

The name is Swedish for “the house mouse”—[husmus](https://sv.wikipedia.org/wiki/Husmus).

Try the app at [husmusen.vercel.app](https://husmusen.vercel.app).

## Structure

The frontend lives in [`husmusen-app`](husmusen-app). The planned backend runs on the household’s local network, with no central backend or server exposed to the public internet. See [architecture.md](docs/architecture.md) for details.

## Project status

Husmusen is in early development. Features and documentation will grow as we go.
